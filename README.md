# The Glycoprotein Atlas

Static GitHub Pages site for the mouse lifespan Glycoprotein Atlas.

The browser application reads versioned JSON files under `data/` and renders the protein explorer locally. The E330 release includes the five atlas datasets (brain, spleen, liver, kidney, plasma) and male and female myelin; EAE is excluded. The custom domain is `glycoproteinatlas.org`.

`data/shards/` contains 256 protein shards generated by the authoritative E330 website-data R Markdown workflow. `data/tvd/` contains the age-comparison exports from the E321 tested-site results; its authoritative export R Markdown file is kept in the E330 folder under the user's canonical `Work/Scripts` directory. The input/QC provenance report stays with the E330 experiment outputs, not on the public website.

To preview local edits, run `python3 -m http.server 8765` from the repository directory and open `http://localhost:8765/`. Opening `index.html` directly as a file will not load the JSON data reliably. This site deploys from `main` at the repository root; committing and pushing `main` publishes the changes through GitHub Pages.


## Comparison views

Age comparisons combine the existing TVD screen with a dominant glycan loss/gain matrix, complete linked hit lists, and age-versus-young-organ distribution plots. Inter-organ comparisons expose all atlas pairs and brain/myelin pairs, pooled or young-only profiles, TVD and heterogeneity, and clickable remodeling/diversity summaries. Site links preserve the precise glycosite, dataset and comparison partner on reload.

The compact derived files use only existing public JSON and can be rebuilt with Python's standard library:

```sh
python3 scripts/build_comparisons.py
python3 -m unittest discover -s tests -v
node --check assets/app.js
node --check assets/comparisons.js
```

See [comparison provenance and panel crosswalk](docs/comparison-views.md) for estimators, thresholds, source hashes and manuscript count checks. The young-only reference view uses the author's recalled rule (≥9 detected animals and ≥18 PSMs per young organ). Its visual pattern has been compared with Figure 3B; exact dot-count equivalence remains unverified because the supplied panel is a raster image with overlapping points and no n labels.

Develop on a feature branch and open a pull request for review. Preview locally over HTTP before merging; pushing `main` publishes to the production domain.
